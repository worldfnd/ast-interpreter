# Ledger: cross-field (bn254 vs goldilocks)

The field axis: the same program compiled and interpreted under both fields at one compiler revision. Integers, bools and structure must agree; `Field` values may differ; failures compare by kind. A gap is a side that could not run the program: predicted by a capability tag, tolerated as a stdlib dependency gap, or, when neither side ran, counted as coverage debt. `projection` says whether the two monomorphized programs project to the same hash. Regenerated by `just ledger` from the two field dumps; CI fails when a fresh run differs from this file.
